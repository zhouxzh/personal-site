Python 编程基础

面向初学者的 Python 基础课程，按天组织语法、程序结构、数据处理和小型实践。本站保留课程讲义、示例代码与 Jupyter Notebook，课程资料不再依赖外部仓库入口。

7 个主题日讲义与练习Jupyter Notebook

学习目标

  • 掌握变量、数据类型、控制流、函数和模块等 Python 基础。
  • 能够读写常见数据文件，并用简单程序完成计算与可视化。
  • 通过逐步练习建立可运行、可解释、可修改的代码习惯。
