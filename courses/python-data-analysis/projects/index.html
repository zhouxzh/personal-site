学生项目目录

每周教程和结课项目中的 projects/<姓名>/ 都指这里。

建议每个学生单独一个目录：

projects/
  <学生姓名或学号>/
    raw/         原始数据（只读）
    scripts/     清洗、分析、建模代码
    output/      图表、CSV、HTML 报告
    report.md    最终结论

本目录默认不提交学生作业，只保留这份说明文件。
