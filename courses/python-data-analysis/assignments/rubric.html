结课项目评分表

维度权重优秀（A）合格（B）待改进（C）
问题与口径20%问题明确，指标定义可计算，数据能回答有问题但口径不够清楚只有题目，没有可计算问题
可复现性25%脚本一键运行，原始数据未改，README 完整能运行但需要手动步骤代码不完整或依赖未说明
数据质量15%能审计并处理缺失、重复、类型问题处理了主要问题未说明清洗决策
分析与图表20%图和表都对应问题，有样本量、口径、来源图可用但信息不完整图多但无解释或误导
结论与局限15%区分事实/推断/局限，结论有依据有结论但缺少局限把相关当因果或夸大结论
展示5%3 分钟讲清闭环讲了步骤但没讲清结论只念代码或 PPT

课堂互评清单

  • [ ] 3 分钟内听懂“问题、方法、结论”。
  • [ ] 每个结论都能指出数据依据。
  • [ ] 报告了样本量和口径。
  • [ ] 图表标题、轴标签、来源完整。
  • [ ] 没有把相关说成因果。
  • [ ] 明确写了局限和下一步。
