Vibe Programming × Python 数据分析

8 周 · 18 学时 · 每周一个晚上 · 每晚上 3 节课 · 每节 45 分钟

这是一门“先定义问题，再让 DeepSeek Harness 生成第一版，人负责运行、验证、追问和决策”的 Python 数据分析课。

本仓库不是一本 pandas 语法手册。它更像一间数据分析工作室：先完整看一个案例，再跟着做一遍，最后换成自己的数据动手做一遍，再用 DSH 审查和迭代。

你将会学到

  • 用自然语言把模糊问题变成可执行的数据分析任务
  • 让 DSH 读取数据、写代码、运行命令、搜索资料、拆子任务
  • 不盲信 AI 输出：检查数据、口径、样本量和结论依据
  • 完成“读取 → 清洗 → EDA → 可视化 → 模型 → 报告”的完整闭环
  • 把课堂项目沉淀成可复现的 .py 脚本和 GitHub Pages 作品

为什么现在是 Vibe Programming

数据分析的真实门槛不再是“记住 pandas 的 API”，而是：

  1. 定义问题：到底要回答什么？
  2. 识别口径：哪个字段、什么时间范围、多少样本？
  3. 验证结果：AI 写的代码真的算对了吗？
  4. 表达结论：这个发现能支撑什么、不能支撑什么？

DSH 负责“预测”：快速生成代码、图表、脚本和方案。学生负责“判断”：选择方向、验证输出、解释业务含义。这就是从 Coder 到 Commander 的转变。

每一课怎么上

所有周次使用同一种课堂结构：

1. 跟着示例做
   拿到一个问题 → DSH 生成第一版 → 运行 → 对照输出 → 解释结果

2. 自己动手做
   换数据、换字段、换问题 → 自己写提示词 → 记录报错和修改

3. 验证与复盘
   检查清单 → DSH 反方审查 → 写“我验证了什么、还有哪些不确定”

快速开始

pip install -r requirements.txt

然后打开 DSH Web GUI，把本仓库作为 workspace：

http://127.0.0.1:3080

第一节课从 01-认识Agent与第一个数据问题.md 开始，先运行：

python scripts/01-agent/02-read-airbnb.py

参考写法

本课程参考了 GitHub 上两个成熟的 Vibe Programming 开源教程：

  • datawhalechina/easy-vibe：从零开始学 AI 编程，用“先看示例 + 自己动手做”组织课程
  • datawhalechina/vibe-vibe：系统化的 Vibe Coding 教程，强调从“写代码”转向“对话式创作”

本仓库保留 Python 数据分析的专业内容，但教学主线改为与它们一致：先讲问题，再做项目，最后沉淀技能。

期末报告与评分

总评成绩 = 平时分 40% + 期末报告 60%。

期末报告要求：

  • 纸质版提交，正文不少于 4 页，不含封面和目录。
  • 从本课程 Week 1-7 数据中选一个主数据集（或者自己查找到的能够合法获取的数据），写清数据来源、字段和样本量。
  • 报告必须包含：
    • 问题：要回答什么，为什么值得分析。
    • 程序解析：关键代码说明，写清读数据、清洗、分析和输出的步骤。
    • 数据分析：至少有一个可复现的分析结果，并带样本量和指标口径。
    • 数据分析图：至少一张图，写清横轴、纵轴、单位和图回答的问题。
    • 结论与局限：写出“我验证了什么、还有哪些不确定、下一步怎么做”。
  • 代码和图片必须来自你自己运行的结果，不贴虚拟占位图。
  • 不允许只复制最终代码；要保留报错、修改和追问记录，并把关键迭代写进报告。
